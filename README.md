# Dastyor Burger: учёт

Учёт для цеха бургеров и хот-догов: сырьё, производство, отгрузки в магазины, возвраты, долги.

## Что умеет (этап 1)

- **Сырьё и закупки.** Каждая закупка с ценой за единицу. Остаток и средняя цена считаются сами, если сырья мало, оно подсвечивается.
- **Рецепты.** Сколько сырья уходит на 1 штуку. По рецепту сразу видно себестоимость и прибыль с одной штуки.
- **Производство.** Записали «сделали 300 хот-догов», и сырьё списалось по рецепту. Если сырья не хватает, система не даст сохранить.
- **Отгрузки.** Магазин, продукты, сколько оплатили сразу. Остаток уходит магазину в долг.
- **Возвраты** с причиной (просрочено, брак, не продалось). Уменьшают долг магазина.
- **Оплаты долгов** от магазинов и поставщикам.
- **Долги** в обе стороны: в списке магазинов видно «долг нам», в списке поставщиков «мы должны».
- **Расходы цеха**: зарплата, аренда, свет, бензин.

## Дашборд (этап 2)

Главная страница сайта. Показывает выручку, прибыль, возвраты и долги за сегодня, 7 дней, 30 дней или всё время. Там же графики продаж по дням и по районам, таблицы по магазинам (продажи, % возвратов, долг) и по продуктам (себестоимость, прибыль с 1 шт, остаток), остатки сырья и долги поставщикам.

## Telegram-бот (этап 3)

Магазины заказывают через бота, а владелец получает каждый заказ с кнопками «Подтвердить» и «Отклонить».

**Магазин** в боте может:
- сделать заказ: выбрать продукт, написать количество, отправить;
- посмотреть свой долг;
- посмотреть последние заказы.

**Владелец** получает уведомления о новых заказах, а кнопка «Сводка» показывает новые заказы, что заканчивается и кто сколько должен.

**Как подключить:**
1. В Telegram напишите @BotFather, команда `/newbot`, придумайте имя. Он пришлёт токен.
2. Узнайте свой Telegram ID у @userinfobot.
3. Впишите в `.env` `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` (имя бота без @) и `OWNER_TELEGRAM_IDS`.
4. Запустите бота: `docker compose --profile bot up -d --build` (на своём компьютере: `python manage.py run_bot`).
5. В админке откройте магазин, там будет ссылка для подключения. Отправьте её магазину: он нажмёт и сразу подключится.

Подтверждённые заказы видны в разделе «Заказы из бота». Выберите их и действие «Оформить отгрузку», и они станут отгрузками. Оплату потом внесите в самой отгрузке.

## Бот для владельца и сотрудников (этап 4)

Владелец (его ID в `OWNER_TELEGRAM_IDS`) и сотрудники вносят данные прямо из бота:

- **Новый магазин**: название, фирма, район, адрес, локация, телефон. Бот сразу выдаёт ссылку для магазина.
- **Приход сырья**: поставщик, сырьё, количество и цена, сколько оплатили. Остаток уходит в долг поставщику.
- **Загрузить машину**: товар уезжает из цеха в машину. Больше, чем есть в цеху, загрузить нельзя.
- **Отгрузка в магазин**: с машины, можно по заказу магазина из бота; оплата сразу или в долг. Магазину приходит чек.
- **Возврат**: от магазина, с причиной; уменьшает его долг.
- **Остаток в машине**: что осталось и сколько денег собрано за день; кнопка «Сдать остаток в цех».
- **Новый сотрудник** (только владелец): бот даёт ссылку, по которой сотрудник подключается.

Обо всём, что внёс сотрудник, бот пишет владельцу. Машины и сотрудники есть и на сайте. Там у сотрудника можно указать «Обычно ездит на», тогда бот не спрашивает машину. Остаток продукта считается отдельно по цеху и по каждой машине, на дашборде есть таблица «Машины».

## Срок годности и контроль магазинов

- У продукта есть «Срок годности, дней» (по умолчанию 5, меняется в списке продуктов).
- Для каждого магазина программа знает дату последней поставки и до какого числа годен товар (по самому короткому сроку из привезённого). На дашборде это таблица «Последняя поставка и срок годности»: строки, где срок кончается, горят красным. Рядом график посещений по дням.
- Каждый день в 9:00 (переменная `REMINDER_HOUR`) бот пишет владельцу и сотрудникам, у которых в поле «Районы» есть район магазина: за 2 дня до конца срока, за день и в последний день, если магазин не заказал. При сроке 5 дней это 3-й, 4-й и 5-й день.
- Когда срок прошёл, бот предупреждает о просрочке каждый день и даёт кнопки «Пропустить» (до следующей поставки) и «В архив». Магазин выходит из архива сам, когда закажет или получит товар.
- На дашборде есть рейтинг лучших магазинов и продуктов и таблица «Кто больше возвращает» с убытком по себестоимости.

## Запуск на своём компьютере

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py demo_data      # необязательно: примерные данные
python manage.py runserver
```

Откройте http://127.0.0.1:8000 и войдите под созданным пользователем. Откроется дашборд, данные вносятся по ссылке «Внести данные».

## Запуск на сервере

На чистом сервере Ubuntu (например, бесплатный Oracle Cloud):

```bash
git clone https://github.com/respectme707-stack/dastyor-burger.git
bash dastyor-burger/install.sh
```

Скрипт поставит Docker, откроет порт 80, спросит токен бота и ваш Telegram ID, сам придумает пароли, запустит сайт и бота и попросит создать логин владельца. В Oracle Cloud порт 80 нужно ещё открыть в панели: Networking → Virtual Cloud Networks → ваша сеть → Security Lists → Default → Add Ingress Rule (Source CIDR `0.0.0.0/0`, порт `80`).

Обновить до новой версии:

```bash
cd ~/dastyor-burger && git pull && bash install.sh
```

### Вручную (Docker)

```bash
cp .env.example .env            # впишите свои SECRET_KEY и DB_PASSWORD
docker compose up -d --build
docker compose exec web python manage.py createsuperuser
```

Программа откроется по IP сервера на 80-м порту.
