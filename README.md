# Dastyor Burger: учёт

Учёт для цеха бургеров и хот-догов: сырьё, производство, отгрузки в магазины, возвраты, долги.

## Что умеет (этап 1)

- **Сырьё и закупки.** Каждая закупка с ценой за единицу. Остаток и средняя цена считаются сами, если сырья мало, оно подсвечивается.
- **Рецепты.** Сколько сырья уходит на 1 штуку. По рецепту сразу видно себестоимость и прибыль с одной штуки.
- **Производство.** Записали «сделали 300 хот-догов», и сырьё списалось по рецепту. Если сырья не хватает, система не даст сохранить.
- **Отгрузки.** Магазин, продукты, сколько оплатили сразу. Остаток уходит магазину в долг.
- **Возвраты** с причиной (просрочено, брак, не продалось). Уменьшают долг магазина.
- **Оплаты долгов** от магазинов и поставщикам.
- **Долги** в обе стороны: в списке магазинов видно «долг нам», в списке поставщиков «мы должны».
- **Расходы цеха**: зарплата, аренда, свет, бензин.

## Дашборд (этап 2)

Главная страница сайта. Показывает выручку, прибыль, возвраты и долги за сегодня, 7 дней, 30 дней или всё время. Там же графики продаж по дням и по районам, таблицы по магазинам (продажи, % возвратов, долг) и по продуктам (себестоимость, прибыль с 1 шт, остаток), остатки сырья и долги поставщикам.

Дальше будет Telegram-бот для заказов (этап 3).

## Запуск на своём компьютере

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py demo_data      # необязательно: примерные данные
python manage.py runserver
```

Откройте http://127.0.0.1:8000 и войдите под созданным пользователем. Откроется дашборд, данные вносятся по ссылке «Внести данные».

## Запуск на сервере (Docker)

```bash
cp .env.example .env            # впишите свои SECRET_KEY и DB_PASSWORD
docker compose up -d --build
docker compose exec web python manage.py createsuperuser
```

Программа откроется по IP сервера на 80-м порту.
